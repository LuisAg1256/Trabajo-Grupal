# Evidencias pendientes — SensorTrack

Guardar aquí capturas y videos reales tomados durante la prueba. No añadir
credenciales, claves ni datos personales de ubicación sin autorización.

## Dispositivo (`dispositivo/`)

- [ ] Splash y pantalla Inicio con estado de conexión visible.
- [ ] Pantallas Sensores, Historial y Estadísticas.
- [ ] Detalle de una medición.
- [ ] Identificar modelo del teléfono en la descripción de la evidencia.

## Sensores (`sensores/`)

- [ ] Video corto mostrando cambios de acelerómetro y giroscopio al mover el teléfono.
- [ ] Captura del GPS con precisión visible.
- [ ] Captura de ausencia/permiso denegado si se usa como demostración de errores.

## Supabase (`supabase/`)

- [ ] Table Editor con filas de ejemplo (ocultar datos personales).
- [ ] Resultado de consultas SQL de conteo y `MIN`/`MAX`.
- [ ] Resultado de `SELECT public.sensor_stats();` y comparación con la pantalla.
- [ ] Evidencia de las políticas RLS aplicadas.

## Convención de nombres

Usar nombres claros y numerados, por ejemplo `05-estadisticas-dispositivo.png`,
`05-estadisticas-supabase.png` y `02-sensores-en-vivo.mp4`.

Las casillas quedan pendientes hasta que el equipo agregue los archivos reales.
